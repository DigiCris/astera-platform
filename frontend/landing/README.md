# Astera Finance Landing

Static landing page for Astera Finance.

## Files

- `index.html`: self-contained HTML/CSS/JS landing page
- `assets/`: Astera branding, favicon, banner and architecture images

## Local preview

Open `index.html` in the browser.

## Recommended routes

- `/` -> landing
- `/app` -> product demo / platform

## Deployment recommendation

Use Vercel for the frontend. The landing can be the root route, and the platform can live under `/app`.
